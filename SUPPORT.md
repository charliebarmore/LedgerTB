# Support

LedgerTB is open-source software provided under the MIT License and does not
include guaranteed response times or professional accounting support.

For a reproducible software bug, use the bug report form in the GitHub issue
tracker. For a product idea, use the feature request form. Before posting,
search existing issues and confirm the problem occurs on the latest release or
current `main` when practical.

Never upload real client books, bank statements, credentials, API keys, tax
identifiers, or unredacted logs and screenshots. Create a minimal example with
sanitized data instead.

Suspected security vulnerabilities must not be reported publicly. Follow
`SECURITY.md` and email **info@ledgerlabs.co**.

Questions about accounting treatment, tax positions, compliance, or whether an
output is appropriate for a client require professional judgment and are
outside the project's software-support scope.
