Balanced is the start. Reviewed is the finish.

Close Map turns the trial balance into an account-by-account close plan. Compare prior year, keep support beside the balance, and see exactly what is ready for review—and what changed afterward.

01 / SUPPORT

Keep the conclusion with the balance.

Store the explanation, lead-sheet assignment, evidence references, and review notes where the account is evaluated.

02 / SIGN OFF

Separate preparation from review.

Preparer and reviewer states are explicit, and an account cannot skip the required review sequence.

03 / STAY CURRENT

Know when finished work moved.

A later entry affecting a signed-off account automatically returns it to Changed so stale review cannot look complete.

The workflow

One path from source activity to a finished close.

01 / SET UP

Start with the chart

Use an entity-aware template or import the full client chart. Rows that cannot map are reported instead of disappearing silently.

02 / IMPORT

Bring in the activity

Save bank formats, check row continuity, catch duplicates, and review category suggestions before anything reaches the ledger.

03 / ADJUST

Make the judgments

Post balanced journal entries and AJEs against the same trial balance worksheet used to evaluate the accounts.

04 / CLOSE

Review, lock, and export

Run deterministic book checks, finish the Close Map, reconcile, lock the fiscal year, and produce branded PDF and Excel close packages.

Audit history

Every change carries the operating-system account that made it. Automated work is attributed separately and never presented as yours.

Firm mode

Keep books on a shared drive while the app stays installed locally. An in-use lock prevents two writers from opening the same book.

AI assistant

Useful access, with a hard ceiling.

Connect Claude or another MCP client to the book you have open. You choose the access level for that book, and the database engine enforces the boundary.

read

Query trial balances, statements, ledgers, entries, book-review findings, and Close Map readiness. The ledger remains untouched.

propose

Set up clients and charts, stage statement rows, file draft entries, and propose Close Map explanations for human review.

post

Append balanced entries directly after an explicit warning. Assistant access can never update or delete ledger history.

The access level lives outside the assistant's reach in the operating system's credential vault. Each book is authorized separately, and every assistant action is audit-attributed “(AI).”

Encrypted at rest
