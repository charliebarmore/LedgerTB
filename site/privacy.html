Privacy & Data Practices

Effective August 13, 2026

LedgerTB has no Ledger Labs cloud account or hosted bookkeeping database. Official builds keep the active book in an encrypted database at a location the user controls. Optional AI and MCP features can send selected data to providers the user configures.

Desktop data

LedgerTB stores records, client details, attachments, audit history, branding, and settings in the active book file. The user chooses whether that file is in LedgerTB's local data folder or another location, including shared storage. Backups and exports go to user-chosen locations.

Official release builds encrypt books and LedgerTB-created backups at rest with SQLCipher. A source build without SQLCipher displays an unencrypted-mode warning and should not be used for real books. Ledger Labs LLC does not receive a book merely because LedgerTB is used and cannot recover a lost passphrase or retrieve a user-controlled book.

If “Remember on this computer” is enabled, a derived unlock key is kept in the operating-system credential vault. Enabling MCP stores a book-specific derived key, identity, access level, and approved export folder in that vault so the local MCP process can enforce the user's choices.

Optional AI features

LedgerTB operates without an AI key. When Anthropic-powered features are enabled, LedgerTB sends the information described beside that feature. Depending on the feature, this may include dates, descriptions, amounts, account names and numbers, transaction details, or statement text. A key saved in LedgerTB is kept in the operating-system credential vault.

Requests go directly from the user's computer to Anthropic under the user's Anthropic account, agreement, and service settings. Ledger Labs LLC does not receive those requests.

Optional MCP access

MCP is off until enabled separately for a book. LedgerTB's MCP server uses local standard input/output and does not listen on a network port. The connected MCP client may nevertheless send tool requests and data returned by LedgerTB to the AI provider configured in that client.

Before enabling MCP for client information, the user should approve the client and provider, including retention, training, confidentiality, security, location, and incident-response terms. A level change or revocation takes effect on the next LedgerTB tool call.

Website and downloads

The static marketing site is hosted by Cloudflare Pages. Ledger Labs LLC does not add analytics scripts, advertising pixels, accounts, or contact forms. Cloudflare may process ordinary request data—such as IP address, browser information, URL, timestamp, and security signals—to deliver and protect the site. The site requests Google Fonts, so a visitor's browser may connect to Google while loading a page.

GitHub hosts source code and release downloads. Cloudflare, Google, and GitHub apply their own terms and privacy practices. Links to Ledger Labs, AI Lab for Accountants, Anthropic, and other services lead to third-party sites.

Messages and security reports

If someone contacts Ledger Labs LLC, we receive the address, message, attachments, and details they provide. We use them to respond, investigate, secure LedgerTB, maintain necessary records, and comply with law. Do not send live credentials or client records in an initial report.

Correspondence is retained only as reasonably necessary for those purposes, subject to legal, security, and recordkeeping needs.

Choices and responsibilities

The user controls book and backup locations, exports, the AI key, MCP enablement and level, approved export folders, and connected providers. MCP and saved credentials can be removed in LedgerTB. Uninstalling the app does not remove book files.

Ledger Labs LLC does not sell personal information received through LedgerTB or use it for cross-context behavioral advertising. LedgerTB is intended for professional use and is not directed to children.

The person or firm controlling a book is responsible for authority, required notices, provider configuration, retention, and requests to access or delete information in that book.

Changes and contact

Material revisions will update the effective date. Questions or requests concerning information held by Ledger Labs LLC may be sent to info@ledgerlabs.co. Because Ledger Labs LLC generally does not receive desktop book data, requests concerning a local book ordinarily belong with the person or firm controlling it.
